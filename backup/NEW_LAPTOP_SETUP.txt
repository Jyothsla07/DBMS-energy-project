Setting up energy-db on a new laptop
====================================

1. Unzip energy-db-transfer.zip (e.g. to D:\energy-db) and open a terminal in that folder.

2. Install:
   - MySQL Server 8.0 (add C:\Program Files\MySQL\MySQL Server 8.0\bin to PATH)
   - Anaconda (Python)
   - pip install pandas sqlalchemy pymysql cryptography scikit-learn matplotlib jupyter python-dotenv
   - PyTorch, matching the GPU:
       Intel GPU:  pip install torch --index-url https://download.pytorch.org/whl/xpu
       NVIDIA GPU: see https://pytorch.org/get-started/locally/
       No GPU:     pip install torch
   - pip install transformers accelerate

3. Restore the database (creates energydb with all 315,648 rows):
       mysql -u root -p < backup/energydb.sql
   PowerShell does not support "<", so there use:
       mysql -u root -p -e "source backup/energydb.sql"

4. Edit .env: set MYSQL_PWD to the new laptop's MySQL root password.

5. Language model (~6 GB): unzip qwen-model-transfer.zip into
       C:\Users\<you>\.cache\huggingface\hub\
   (create the folder if it does not exist), so you end up with
       ...\hub\models--Qwen--Qwen2.5-Coder-3B-Instruct\snapshots\...
   If you skip this, the model downloads automatically on the first run.

6. Test:
       python python/ask_web.py
   then open http://localhost:8000
